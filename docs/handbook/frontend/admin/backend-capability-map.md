# 管理端后端能力映射

> 状态：当前有效
> 适用范围：`frontend/apps/admin/` 与管理端后端接口的消费边界
> 最后校准：2026-07-30
> 对应代码：`frontend/apps/admin/src/`、`MyBlog-springboot-v2/src/main/java/com/tyb/myblog/v2/`
> 权威程度：前后端能力映射

## 总体边界

1. 文章、分类、标签、评论、友链、附件、站点配置、账号资料、密码和统计写接口均已有管理端入口。
2. 页面优先复用现有 API、`use*` 管理函数、Element Plus 控件和 i18n 结构，不为覆盖率新建无业务价值的详情页或请求。
3. 服务端状态机、全量写入、软删除、公开可见性、权限和统计口径仍是最终约束；前端提示和校验不能替代后端。
4. 后端不支持的查询、排序或统计口径不得用当前页本地处理伪装成服务端能力。

## 路由与页面入口

`/api/admin/security-probe` 只用于安全测试，不属于产品菜单。

| 模块 | 后端能力 | 管理端消费边界 |
| --- | --- | --- |
| 文章 | 分页与全部现有筛选、白名单排序、详情、创建、完整更新、软删除、回收站、恢复 | 列表、编辑器和回收站已消费；普通列表按更新时间、创建时间、发布时间或评论数服务端排序 |
| 分类 | 列表、详情、创建、完整更新、批量排序、引用保护删除 | 列表已含页面所需字段，不为详情接口单独加入口 |
| 标签 | 列表、详情、创建、完整更新、引用保护删除 | 列表已含页面所需字段，不为详情接口单独加入口 |
| 评论 | 列表筛选、创建时间排序、通过、隐藏、恢复、回复、软删除 | 页面消费全部操作与查询参数；创建时间使用服务端升降序 |
| 友链 | 列表、详情、创建、完整更新、显示状态、批量排序、软删除 | 列表只发送 `page`、`size`；后端不支持关键字或状态筛选 |
| 附件 | 活动分页与白名单排序、已删除分页、详情、上传、软删除、恢复 | 正常附件库按上传时间、文件大小或原始文件名服务端排序；回收站保留删除时间倒序；卡片字段已覆盖详情展示 |
| 站点配置 | 完整读取、完整更新 | 页面完整提交 14 个字段 |
| 当前账号 | 当前用户、资料部分更新、改密 | ADMIN 可修改；DEMO 只读 |
| 认证会话 | 登录、刷新、全端退出 | 由会话服务统一消费 |
| 统计 | `GET /api/admin/stats/dashboard?from&to` | 仪表盘支持合法日期区间和快捷范围；区间与今日指标分组展示，趋势、热门文章和语言分布使用各自空态；热门文章标题可进入文章编辑页 |

## 查询约束

- 文章列表支持 `status`、`categoryId`、`tagId`、`titleKeyword`、`createdFrom/To`、`publishFrom/To`、分页，以及 `updatedAt`、`createdAt`、`publishAt`、`commentCount` 白名单排序；切换排序回到第一页，管理端不做当前页本地排序。
- 评论列表支持现有目标、审核状态、关键字、删除状态筛选与分页，并只允许按 `createdAt` 服务端排序；切换排序回到第一页，审核状态和目标类型不作为排序字段。
- 正常附件库支持按 `createdAt`、`fileSize`、`originalFilename` 服务端排序，切换排序回到第一页；附件回收站仍按删除时间倒序，管理端不发送排序参数。
- 统计自定义范围必须同时提供两端，开始不晚于结束且最多 366 天；缺省使用最近 30 个 JST 自然日。
- `todayPv`、`todayUv` 始终表示 JST 当天；`todayUv` 和趋势 `uv` 是页面与语言分组后的页面日 UV 合计，不是站点级独立访客；顶部文章 `dailyUvSum` 是区间内逐日 UV 之和，不是跨日唯一访客。
- 友链不得恢复关键字/状态控件或当前页本地过滤。确有全局筛选需求时，单独设计后端查询、索引和分页契约。

## 表单与操作语义

- **文章**：非草稿按状态校验标题、正文、分类和发布时间；PASSWORD 新建必须提供口令，编辑留空保留，离开该状态清空；标签最多 20 个并去重；首页槽位只允许已发布文章。
- **评论**：留言板固定使用 `GUESTBOOK / 0`；DEMO 不获取邮箱、IP、User-Agent 等隐私字段；回复只允许活动且已通过的评论；隐藏、删除、恢复和通过的计数影响按后端规则提示。
- **分类、标签、友链**：创建时规范化 slug，编辑时锁定；引用保护、唯一冲突、排序值域和公开状态由后端最终校验。
- **附件**：请求前拒绝超过 10 MiB 的文件；服务端仍校验真实内容；SHA-256 去重可能复用或恢复记录；删除是软删除，不立即移除物理对象。
- **站点配置**：完整提交 14 个字段，三语内容逐字段回退中文；标题、摘要、About Markdown、Logo/Favicon 和 Spotify ID 按后端格式校验。
- **账号**：资料页面说明公开字段并校验格式；改密要求 8–128 字符且不得复用当前密码，成功后所有历史会话失效并重新登录。

## 不单独增加入口的接口

以下详情接口的列表响应已经包含当前页面所需字段；没有新的产品需求时保留 API 封装和测试，不新增详情页、弹窗或额外请求：

- `GET /api/admin/categories/{id}`
- `GET /api/admin/tags/{id}`
- `GET /api/admin/friend-links/{id}`
- `GET /api/admin/attachments/{id}`

同理，友链全局筛选、附件名称/类型查询和统计跨日唯一访客当前没有后端能力；需要时先设计服务端契约。

## 回归要求

修改管理端消费链路时先运行受影响的表单、hook 和页面测试，再执行：

1. `pnpm --dir frontend/apps/admin test`
2. `pnpm --dir frontend/apps/admin typecheck`
3. `pnpm --dir frontend/apps/admin build`
4. `pnpm --dir frontend/apps/admin check:bundle-budget`

接口字段和业务规则分别以 [`../../api/`](../../api/README.md) 与 [`../../product/business-rules.md`](../../product/business-rules.md) 为准。
